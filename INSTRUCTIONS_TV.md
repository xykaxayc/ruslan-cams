# Инструкция по установке и подключению приложения «Монобукет» на Android TV

Данное руководство описывает процесс установки приложения видеонаблюдения «Монобукет» на любые телевизоры, медиаприставки и проекторы под управлением **Android TV** или **Google TV** (Xiaomi, TCL, Sony, Philips, Яндекс.ТВ, Сбер Салют, приставки Android Box и др.).

---

## 1. Ссылка на скачивание актуального APK

* **Прямая ссылка:**  
  `https://monobuket.tabcast.ru/monobuket-tv.apk`

---

## 2. Способы установки на ТВ

### Способ А: Через приложение «Downloader» на ТВ (самый удобный, без проводов и флешек)

1. Откройте **Google Play Store** (или магазин приложений вашей ТВ-системы) на телевизоре.
2. В поиске введите `Downloader` (оранжевая иконка с белой стрелкой, автор *AFTVnews*) и установите его.
3. Запустите Downloader, разрешите ему доступ к файлам при первом запуске.
4. В строке ввода адреса (URL) введите:  
   `https://monobuket.tabcast.ru/monobuket-tv.apk`  
   и нажмите кнопку **Go**.
5. Начнется скачивание файла. По окончании Downloader предложит нажать **Install (Установить)**.
   * *Если телевизор покажет предупреждение безопасности:* нажмите **Настройки (Settings)** -> найдите Downloader в списке и переключите тумблер в положение **Разрешено** (Разрешить установку из неизвестных источников).
   * Вернитесь назад и нажмите **Установить**.
6. Нажмите **Открыть** (Open).

---

### Способ Б: Через USB-флешку

1. На компьютере или телефоне скачайте файл приложения по ссылке:  
   `https://monobuket.tabcast.ru/monobuket-tv.apk`
2. Скопируйте файл `monobuket-tv.apk` на USB-флешку (файловая система FAT32 или exFAT).
3. Вставьте флешку в USB-разъем телевизора или приставки.
4. На телевизоре откройте любой проводник файлов (например, штатный *Медиаплеер*, *Файлы* или бесплатные приложения из магазина: *X-plore File Manager*, *File Commander*).
5. Перейдите на флешку, нажмите на файл `monobuket-tv.apk` и выберите **Установить**.
   * При запросе разрешения на установку сторонних приложений — подтвердите разрешение для проводника.
6. После завершения установки нажмите **Открыть**.

---

### Способ В: Через сеть по ADB (для технических специалистов)

1. Включите режим разработчика на ТВ:  
   `Настройки` -> `Об устройстве` -> нажимайте 7 раз на пункт `Сборка ОС (Build number)`.
2. В меню `Для разработчиков` включите **Отладка по USB / Отладка по сети**.
3. Узнайте IP-адрес ТВ в `Настройки` -> `Сеть и интернет`.
4. С компьютера в терминале выполните:
   ```bash
   adb connect <IP_АДРЕС_ТЕЛЕВИЗОРА>:5555
   adb install -r monobuket-tv.apk
   ```

## 3. Первый запуск и настройка

* Приложение не требует ввода логина или пароля на пульте ТВ: все параметры подключения уже преднастроены.
* При открытии приложение автоматически подключается к серверу `monobuket.tabcast.ru`, получает актуальный список камер и запускает непрерывный живой эфир мозаики всех 8 камер в Full HD.

---

## 4. Управление с пульта (D-Pad)

* **Стрелки (Влево / Вправо / Вверх / Вниз):** перемещение фокуса и выбор интересующей камеры в плитке.
* **Кнопка OK (Центральная кнопка):** развернуть выбранную камеру **на весь экран в максимальном HD-качестве**.
* **Кнопка «Назад» (Back / Return):** вернуться из полноэкранного режима обратно в общую сетку камер.

---

## 5. Удаленное управление с сайта (без использования пульта)

Вы можете удаленно настраивать параметры отображения на ТВ через веб-интерфейс:

1. Откройте в браузере телефона или компьютера:  
   👉 **https://monobuket.tabcast.ru/?token=ruslan2026**
2. В верхней панели нажмите кнопку **⚙️ Настройки ТВ**.
3. Доступные параметры:
   * **Буфер воспроизведения (1.0 — 6.0 сек):**
     * *1.0 — 2.0 сек:* минимальная задержка эфира (рекомендуется при стабильном Wi-Fi / Ethernet).
     * *3.0 — 4.0 сек:* оптимальный режим по умолчанию.
     * *5.0 — 6.0 сек:* повышенная плавность, если сигнал Wi-Fi слабый.
   * **Показывать часы на экране ТВ:** включение/отключение системного виджета времени в правом верхнем углу экрана ТВ.
4. Нажмите **Сохранить настройки**.
5. Телевизор автоматически применит новые параметры в течение 30 секунд.

## 6. Автоматическое обновление (OTA)

* При выходе новых версий приложение автоматически определяет наличие обновления на сервере и предлагает обновиться в один клик.
* Никаких повторных установок вручную производить не потребуется.
